Libur & Sholat: Pengaturan

Ekstensi ini memakai API key API Indonesia milikmu sendiri. Belum punya? Daftar gratis dan buat key di dashboard.apiindonesia.id. Setiap request yang berhasil memakai 2 kredit. Data disimpan sehari di browser supaya tidak boros kredit.

Key disimpan hanya di penyimpanan lokal browser (storage.local) dan hanya dikirim ke use.apiindonesia.id. Kebijakan privasi.
